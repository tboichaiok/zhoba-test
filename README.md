## 🌟 Басты 3D мүмкіндіктер мен модельдер:

1. **Әр тәулікке арналған жеке 3D өсу модельдері (`models/` қалтасында):**
   * **`seed_1day.glb` (1-ші күн):** Тұқымның ісінуі және алғашқы тамыршаның шығуы.
   * **`seed_7day.glb` (7-ші күн):** Өну кезеңі, тамырдың гравитропиялық бағдарға қарай бөлінуі.
   * **`seed_14day.glb` (14-ші күн):** Вегетативті фаза, микрогравитациядағы тамырдың спиральді иірілуі.
   * **`seed_21day.glb` (21-ші күн):** Тәжірибелік циклдің аяқталуы, толық биомасса (ауытқу бұрышы 47.8°).
   * **`clinostat_2axis.glb`:** 2-осьті клиностат (1.5 айн/мин үздіксіз айналу).
   * **`arduino_bioreactor.glb`:** Arduino Uno R3, 4-арналы реле және датчиктер.
   * **`bioreactor_chamber.glb`:** Биореактор өсіру камерасының толық 3D моделі.

2. **3D Интерактивті Цифрлық Егіз (3D Digital Twin Chamber):**
   * Симулятор секциясында тікелей 3D камера орнатылған!
   * **DC Кулер (IN4):** Температура >26.5°C болғанда немесе қызып кету сценарийінде 3D кулердің лопастьтары жоғары жылдамдықпен (2400 RPM) нақты айналады.
   * **Авто-суару сорғысы (IN1):** Топырақ ылғалдылығы <38% түскенде форсункалардан 3D су тамшылары жауып, топырақ түсі дымқылданады.
   * **LED Фитожарық (IN2):** Камера ішіне нақты күлгін-қызыл фотосинтетикалық сәуле шашады.
   * **Керамикалық жылытқыш (IN3):** Суық түскенде (<18.5°C) қып-қызыл болып қызады.
   * Барлық қозғалыстар экрандағы ползуноктармен және сценарийлермен 100% синхронды жұмыс істейді.

3. **Vercel-де бірден ашылуға дайын:**
   * Батниксіз, кез келген құрылғыда (ноутбук, проектор, телефон) жұмыс істейді.
   * `vercel.json` файлдары дұрыс бапталған.

4. **Қазақ тіліне арнайы қаріп (Montserrat & Manrope):**
   * `Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І` әріптері толықтай таза әрі сапалы көрінеді.
